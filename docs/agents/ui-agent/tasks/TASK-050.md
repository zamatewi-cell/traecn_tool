## API 端点

```
GET  /api/stats         # 统计数据
GET  /api/accounts      # 账号列表
POST /api/accounts      # 添加账号
PUT  /api/accounts/:id  # 更新账号
DELETE /api/accounts/:id # 删除账号
GET  /api/queue         # 队列状态
GET  /api/logs          # 日志
WS   /ws               # WebSocket 实时推送
```
