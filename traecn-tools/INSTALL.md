# TraeCN Tools 安装说明

## ? 安装包信息

- **文件名**: `TraeCN.Tools_1.0.0_x64-setup.exe`
- **文件大小**: 约 78 MB
- **适用系统**: Windows 10/11 (x64)
- **版本**: 1.0.0

## ? 安装步骤

1. 双击运行 `TraeCN.Tools_1.0.0_x64-setup.exe`
2. 按照安装向导提示选择安装路径
3. 点击"安装"按钮完成安装
4. 安装完成后会自动启动应用

## ? 功能特性

3. **API 代理配置**
   - 启动/停止代理服务

   - 请求超时设置
   - 开机自启
   - 局域网访问
   - 认证模式（自动/Bearer/无）
   - API Key 管理
   - Web UI 密码
   - User-Agent 覆盖
   - 模型路由配置
   - 多协议支持（OpenAI/Anthropic/Gemini）

4. **其他页面**（开发中）
   - 日志查看
   - 统计信息
   - Token 管理
   - IP 管理
   - 设置

## ? 技术栈

- **前端**: React 18 + TypeScript + Vite 6
- **UI**: Tailwind CSS 3 + Lucide Icons
- **状态管理**: Zustand
- **桌面框架**: Electron 33
- **打包工具**: electron-builder (NSIS)
- **后端**: Go 反向代理服务

## ? 使用说明

### 添加账号

1. 进入"账号管理"页面
2. 点击"添加账号"按钮
3. 系统会自动打开浏览器跳转到 Trae CN 登录页面
4. 完成登录后，账号会自动添加到列表中

### 启动 API 代理

1. 进入"API 代理"页面
2. 配置监听端口（默认：8045）
3. 点击"启动服务"按钮
4. 服务启动后，状态指示器会显示绿色

### 配置模型路由

1. 在"API 代理"页面找到"模型路由"部分
2. 选择预设配置或自定义映射
3. 添加源模型到目标模型的映射关系
4. 保存配置

## ? 数据存储

应用数据存储在：
```
%APPDATA%\TraeCN Tools\traecn-data.json
```

包含：
- 账号列表
- 代理配置
- 设备指纹
- 模型映射

## ?? 注意事项

1. **首次使用**: 需要先添加至少一个账号才能使用代理服务
2. **端口占用**: 如果默认端口 8045 被占用，请修改为其他端口
3. **防火墙**: 首次启动代理服务时，Windows 防火墙可能会提示，请选择"允许"
4. **企业用户**: 当前版本仅支持个人用户 OAuth 登录，企业用户登录功能将在后续版本支持
